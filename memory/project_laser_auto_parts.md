**Mobile responsiveness — FIXED via custom CSS (2026-09-08/09), supersedes the 2026-09-06/07 note below.** Root cause fully diagnosed: all category-hero banner images are 1566×398 (~3.9:1), art-directed with photo+logo lockup in the center-left and a clean gradient zone reserved for text on the right (~x=1100-1566). The hero `<img>` uses `object-cover` with default (centered) `object-position`. On desktop (container ~1520×400, aspect ~3.8:1) the crop shows nearly the whole image as designed. On mobile (container ~390×300, aspect ~1.3:1) `object-cover`'s centered crop zooms in and lands almost exactly on the logo lockup, shoving the "clean" text zone off-frame — so the title/description (vertically centered via the section's `flex items-center`, spans full width) overlaps the logo instead of sitting on empty gradient.
**First attempt (2026-09-08, superseded same day) — crop-to-hide-logo:** right-anchored the crop (`object-position: 100% 50%`) + bumped min-height to 340px so the visible window fell entirely in the clean zone, hiding the logo.
